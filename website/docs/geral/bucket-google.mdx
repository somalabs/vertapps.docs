# Bucket Google

Bucket no Google Cloud Storage para guardar, num só lugar, os arquivos importantes da Vertical de Apps.

<Chips>
  <Chip tone="blue">Google Cloud Storage</Chip>
  <Chip>Projeto mais-cms</Chip>
</Chips>

- **Bucket:** `soma-apps-apn-ios` (projeto `mais-cms`)
- **Link:** [console.cloud.google.com/storage/browser/soma-apps-apn-ios](https://console.cloud.google.com/storage/browser/soma-apps-apn-ios?project=mais-cms)

## O que está salvo

| Arquivo | Uso |
|---|---|
| Certificado do push iOS (APNs) | Envio de push para os apps iOS |

Ao subir um arquivo novo, acrescente uma linha nesta tabela.
