# Update Version

Esta coleção é responsável pelo bottom sheet de sugestão de atualização do APP para versões inferiores a ultima versão do app. O bottom sheet é exibido na home e pode ser fechado pelo usuário.  Ele tem um botão de “Atualizar agora” que redireciona para a loja correspondente ao Sistema Operacional, na página da marca.

<Chips>
  <Chip tone="coral">Update Version</Chip>
  <Chip tone="teal">CMS</Chip>
</Chips>

O número da última versão é cadastrado no Firebase  > Remote Config > Feature Flag.<br />Para que o bottom sheet seja exibida para o usuário, ele precisa ter baixado no dispositivo uma versão que seja inferior a última versão do app. E esta coleção precisa estar publicada e ativa (campo ‘active’ como true).

Inputs:<br />active: O bottom sheet só é exibido se este campo estiver marcado como true.

title: O título do bottom sheet.

description: Texto de descrição do bottom sheet.
