# Trends de busca

Essa coleção é referente o cadastro dos termos mais buscados que fica destacado quando o usuário entra na busca do app. <br />O campo “active” controla a exibição do componente Search Trends. Quando ativo, exibe como ‘em alta’ os titulos definidos no componente “Search Trends”, caso desligado, exibe como ‘em alta’ os titulos trazidos pela vtex.
