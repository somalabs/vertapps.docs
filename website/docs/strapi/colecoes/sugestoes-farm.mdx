## Envio de push:

<b>action</b>: O campo  deve sempre conter o texto <b>`'suggestions'`</b>, pois essa string é utilizada para que o aplicativo identifique a ação correspondente à funcionalidade de sugestões.<br /><b>indentifier</b>: O campo  deve receber o título da sugestão que se deseja direcionar.

Sem quebras de linha ou caracteres especiais que possam interferir na formatação
