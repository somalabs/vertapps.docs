# Force Update Version

Esta coleção é responsável pela tela de bloqueio de acesso ao APP para versões bloqueadas ou inferiores a versão mínima estabelecida. Quando esta tela é exibida o usuário não consegue sair dela, e portanto, não consegue navegar no app. Ela tem um botão de “Atualizar agora” que redireciona para a loja correspondente ao Sistema Operacional, na página da marca.

<Chips>
  <Chip tone="coral">Force Update Version</Chip>
  <Chip tone="teal">CMS</Chip>
</Chips>

Os números de versão mínima e bloqueada são cadastrados no Firebase  > Remote Config > Feature Flag.<br />Para que a tela seja exibida para o usuário, ele precisa ter baixado no dispositivo uma versão que esteja bloqueada, ou que seja inferior a mínima, e esta coleção precisa estar publicada e ativa (campo ‘active’ como true).

Inputs:<br />active: A tela só é exibida se este campo estiver marcado como true.

title: O título da página

description: Texto de descrição da página

image\_background: Imagem de fundo da página (em algumas marcas \[Animale/CB\] a imagem de fundo precisa ser escura, nas outras, clara).

invert\_button\_color: Inverter cores do botão. Quando marcado, o app inverte as cores do botão, do título e da descrição da tela, para permitir arte de fundo escura com texto claro. Desmarcado (padrão) ou sem valor, a tela fica com as cores atuais da marca. Documentos já publicados só passam a ter o campo depois de salvos e publicados de novo. Campo opcional.
