<DocTitle brand="Farm ETC">Header Geral PDC ETC</DocTitle>

Essa coleção é onde poderá ser cadastrado um Header mais geral, que será utilizado em <b>todas</b> as PDCs do ETC. Caso haja um header cadastrado via Media Kit, o header do Media Kit terá maior prioridade e o geral será ignorado.<br /><br />Para saber como preencher esse componente, consulte: [Documentação](https://www.notion.so/gruposoma/Strapi-CMS-8050d90e377246f5b1765cc0828a6718?source=copy_link#21f690e9a7e28095a2a9d68963bd99c5)
