<DocTitle brand="Hering">Turbo</DocTitle>

Esta coleção tem a função de deixar habilitada/desabilitada a funcionalidade do Turbo. Assim como outras collections do strapi, deve ter seu documento publicado para refletir no aplicativo. Caso não haja coleções publicadas, o default será false, ou seja, o turbo não será exibido para os usuários.<br />Essa collection não controla as opções de entrega.
