# Busca Vazia

A coleção de busca vazia é composta por dois componentes, <b>Categories Mosaic</b> e <b>Showcase Banner</b>. Os dois são opcionais e ao ser preenchido devem ser mostrados quando o usuário digita algo que não pode ser encontrado.<br />
