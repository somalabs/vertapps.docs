# Media kit

Coleção utilizada para inserção de componentes de mídia em páginas de categoria/coleção (PDCs). Esses componentes serão inseridos entre os produtos da PDC especificada, e o intervalo entre eles poderá ser configurado.<br /><br /><b>Media kit versão</b> <b>Farm</b>

<b>Nome interno:</b> Apenas um campo que servirá para identificar mais facilmente esse documento em caso de múltiplos<br /><b>Categoria/Cluster:</b> Será a categoria ou coleção onde serão inseridos os componentes do Media kit. PRECISA COMEÇAR COM ‘/’. Exemplo: “/productclusterids/123”.

## Componentes

Media Kit Banner

![Media kit — figura 2](/img/strapi/colecoes/media-kit/img-02.webp)

<b>Mostrar antes do produto:</b> Em qual posição o banner será mostrado (Campo obrigatório)<br /><b>Tamanho:</b> O tamanho desse banner (Campo opcional)<br /><b>Imagem:</b> Imagem do banner (Campo obrigatório)<br /><b>Navegação:</b> Navegação dinâmica que será realizada ao clique do usuário no banner. Consulte [aqui](../navegacao-dinamica.mdx) para saber mais detalhes. (Campo obrigatório)

<b>video\_url:</b> campo para preencher com o link da vimeo, do video que deve ser exibido. Caso tenha imagem e video cadastrado, prioriza o video.
