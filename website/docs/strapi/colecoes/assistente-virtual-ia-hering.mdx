Esse documento é utilizado para cadastrar os componentes da tela de assistente de IA na Hering.

<Chips>
  <Chip tone="coral">Assistente Virtual IA</Chip>
  <Chip tone="amber">HERING</Chip>
  <Chip tone="teal">CMS</Chip>
</Chips>

Para acessar essa página é só usar o padrão de [navegação dinâmica](../navegacao-dinamica.mdx), usando o padrão para esta página em específico, que é basicamente através da URL <b>/ai-assistant.</b> Ou seja, para conseguir acessar essa tela, basta cadastrar um banner ou qualquer outro componente com navegação dinâmica, e passar essa url no campo de navegação, além é claro de cadastrar o documento.

:::warning

ATENÇÃO: Para a tela de assistente IA funcionar corretamente, é necessário que esse componente esteja cadastrado.

:::
