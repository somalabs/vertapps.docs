# Ingressos de Eventos

Esta coleção é responsável por armazenar os ingressos que serão exibidos no aplicativo.

<Chips>
  <Chip tone="coral">Ingressos de Eventos</Chip>
  <Chip tone="teal">CMS</Chip>
</Chips>

Ela possui um único componente de <b>Ingresso</b>, permitindo o cadastro de uma lista de ingressos.

⚠️ <b>Importante:</b>

Cada ingresso cadastrado deve obrigatoriamente possuir um <b>identificador único</b>, que precisa estar previamente registrado no <b>Master Data</b>.

Esse identificador é utilizado para vincular o ingresso ao usuário e permitir sua correta exibição no app.<br />
