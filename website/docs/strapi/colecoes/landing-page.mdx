# Landing Page

A Landing Page é uma coleção onde a marca pode ter diversas coleções publicas ao mesmo tempo (não apenas uma como acontece na home). Cada coleção publicada corresponde a uma tela a ser exibida no app.

<Chips>
  <Chip tone="coral">Landing Page</Chip>
  <Chip tone="teal">CMS</Chip>
</Chips>

A coleção é simples, contém todos os componentes do Farm Rio e alguns do Farm Etc que foram comportados pela estrutura de scroll utilizada (a mesma da Farm Rio).

Para redirecionar o usuário para a uma landing page específica, basta utilizar a [navegação dinâmica](../navegacao-dinamica.mdx). Em resumo o redirecionamento será “landing-page/&#123;nome da coleção&#125;”, por exemplo “landing-page/Sustentabilidade”.<br />
