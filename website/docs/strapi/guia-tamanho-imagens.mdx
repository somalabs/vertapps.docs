## Regras gerais

- O formato indicado para imagens é .jpg
- Os campos “image”/”media” dos componentes, aceitam também Gifs.
- Os vídeos sempre deverão ser informados via URL.
- O peso maximo das medias video é de 3MB.
## Contexto
> Como estimar corretamente o tamanho das imagens que serão publicadas no app, em diferentes cenários e dispositivos.

Considerações: 
- O app **prioriza a qualidade das imagens**, garantindo a maior resolução possível.
- **Proporções sempre preservadas** → nada deve distorcer.
- **Preenchimento total do espaço** → até o limite da resolução original da imagem.
- **IMPORTANTE: **Se a imagem for **menor do que o necessário** para o dispositivo mais denso, ela ficará pixelada.
- Dispositivos diferentes tem tamanhos mínimos de imagem diferentes.
## 🖼 Como o app lida com (algumas*) imagens 
- **Mantém proporção (aspect ratio)**
- **Usa todo o espaço disponível** (`BoxFit.cover`)
- **Considera densidade de pixels (DPR)** para nitidez
- **Nunca aumenta acima da resolução original** para evitar perda de qualidade
\* Alguns componentes tem aspectRatio aplicado.
## 📱 Tamanhos e densidades de referência 

| Dispositivo | Largura lógica (dp) | DPR | Largura física (px) | Altura física (px) |
| --- | --- | --- | --- | --- |
| iPhone 14 Pro Max | 430 | 3.0 | 1290 | 2796 |
| iPhone 13/14 | 390 | 3.0 | 1170 | 2532 |
| Android comum (FHD) | 411 | 3.0 | 1233 | 2630 |
| Android pequeno | 360 | 2.5 | 900 | 1600 |
| iPad Pro 12.9 | 1024 | 2.0 | 2048 | 2732 |
> Dica: Para garantir qualidade em todos os casos, use sempre o maior DPR e a maior largura lógica como referência.
## 📐 Fórmula de cálcular 
```text
larguraImagemPx = larguraContainerDp × DPRmáximo
alturaImagemPx  = alturaContainerDp × DPRmáximo
```
**Onde:**
- **larguraContainerDp** = largura do espaço que a imagem vai ocupar no layout.
- **alturaContainerDp** = altura do espaço no layout (pode ser fixa ou percentual).
- **DPRmáximo** = densidade de pixels do maior dispositivo que vamos suportar (normalmente **3.0** para smartphones, **2.0** para tablets).
## 📚 Exemplos do calculo do tamanho da imagem 
# Exemplo 1 — Banner de tela cheia (40% da altura)
📱 iPhone 14 Pro Max (430dp largura, 3.0 DPR, altura física 2796px):
- Largura: `430 × 3 = 1290px`
- Altura: `2796 × 0.40 = 1118px`
**✅ Tamanho mínimo:** **1290 × 1118 pixels**
# Exemplo 2 — Duas imagens lado a lado
📱 iPhone 14 Pro Max (padding total horizontal = 48dp, altura fixa 450dp):
- Largura container (dp): `(430 - 48) / 2 = 191dp`
- Largura container (px): `191 × 3 = 573px`
- Altura container (px): `450 × 3 = 1350px`
**✅ Tamanho mínimo:** **573 × 1350 pixels**
# Exemplo 3 — Banner ocupando 30% da tela
📱 iPhone 14 Pro Max:
- Largura: `430 × 3 = 1290px`
- Altura: `2796 × 0.30 = 838px`
**✅ Tamanho mínimo:** **1290 × 838 pixels**
## 💡 Dicas para Designers e POs
- Sempre exporte **maior** que o tamanho mínimo calculado.

### 🔹 3. Fórmula rápida pra saber o quanto corta
Se a imagem tem `aspectImage = widthImage / heightImage`,
e o container tem `aspectContainer = 0.521`:
- Se `aspectImage > aspectContainer` → corta nas **laterais**
- Se `aspectImage < aspectContainer` → corta **em cima/baixo**
Exemplo com `1080x1920`:
```text
aspectImage = 1080 / 1920 = 0.562
aspectContainer = 0.521
0.562 > 0.521 → leve corte lateral (~7%)
```

### Carousel List (double image)

Como as imagens são empilhadas verticalmente, **cada uma ocupará metade da altura da tela**.
👉 Então, se a tela total é **1080×1920**, cada imagem deve idealmente ocupar **1080×960**.
Essa proporção é:
> 1080 / 960 = 1.125
Ou seja, a **altura é 0.89× da largura**.

## 🎯 Recomendação prática para o time de design
### ✅ Quando for **1 imagem (full screen)**:
Use:
- **1080×1920 px** (ou 9:16)
- Ou, se preferirem a variação atual, **1080×1624 px** também funciona.
### ✅ Quando for **2 imagens (double media)**:
Cada imagem deve ter aproximadamente:
- **1080×960 px**
*(metade da altura total da tela 1080×1920)*
### ⚠️ Dicas importantes
- Mantenham **a mesma largura** (1080px) entre as imagens.
- As **duas imagens devem ter alturas idênticas**, para se encaixarem perfeitamente.
- Se quiserem outra proporção de tela (ex: 1080×1624 em vez de 1080×1920), basta dividir a altura por 2:
- Exemplo: **1080×812 px** cada (metade de 1624).
