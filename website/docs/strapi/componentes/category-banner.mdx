# Category Banner

Componente Banner de imagem/vídeo onde é possível o cadastro de um link de redirecionamento ao click do usuário. Também é possível o cadastro de título, subtítulo, descrição e CTA. ATENÇÃO: Esse componente atualmente pode possuir o mesmo comportamento do antigo Hero e também do antigo External Link Banner, ou seja, esses dois componentes foram juntados em um só, e possuem as propriedades de todos.
