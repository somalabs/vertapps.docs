# Carousel Banner

Componente de carrossel, semelhante ao funcionamento do componente *carroussel_list*, porém com o tamanho adaptável ao tamanho da imagem, assim como funciona o componente *category banner.*

<Chips>
  <Chip tone="coral">Carousel Banner</Chip>
  <Chip tone="teal">CMS</Chip>
</Chips>

## Inputs

![Carousel Banner — figura 1](/img/strapi/carousel-banner/img-01.webp)

<b>autoplay:</b> Indica se o carrossel deverá passar entre os banners automaticamente, sem que o usuário precise interagir com o componente. Campo opcional.

<b>loop:</b> Indica se o carrossel deve voltar ao início após exibir o último banner. Campo opcional.

<b>delay:</b> Quantidade de segundos que serão esperados antes de transicionar para o próximo banner caso o autoplay esteja ativado. Campo opcional.

<b>items:</b> itens que serão exibidos no carrossel. (repetível)

<b>media:</b> Imagem ou vídeo do item. Campo obrigatório.

<b>navigate\_to:</b> URL de navegação que será executada ao clicar no banner. Campo opcional. Segue o padrão de [navegação dinâmica](../navegacao-dinamica.mdx).

<b>banner\_name\_ga4:</b> ID e nome da promoção usados para eventos de analytics, separados por ///. Campo obrigatório.
