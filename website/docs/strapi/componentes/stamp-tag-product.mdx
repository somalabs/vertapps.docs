# Stamp Tag Product

Este componente tem prioridade sobre a stamp tag. Ou seja, caso o produto tenha a coleção cadastrada na stamp Tag, e tb tenha o id corresponente ao cadastrado na stampTagProduct, então será exibida a tag de stampTagProduct.
