# Stamp Tag Product

Este componente tem prioridade sobre a stamp tag. Ou seja, caso o produto tenha a coleção cadastrada na stamp Tag, e tb tenha o id corresponente ao cadastrado na stampTagProduct, então será exibida a tag de stampTagProduct.

<Chips>
  <Chip tone="coral">Stamp Tag Product</Chip>
  <Chip tone="teal">CMS</Chip>
</Chips>

## Inputs

<b>tag\_text:</b> Texto da tag a ser exibida

<b>products\_ids</b>: ID dos produtos que deve exibir a tag, cada id de produto deve ser separado por ‘;’.<br />Exemplo: “15432; 14965; 52362”

<b>colors:</b> Definição das cores da tag
