# Search suggested products

É o componente disponibilizado dentro da coleção Trends de busca. Deve ser cadastrado apenas um dele na coleção (caso tenha mais de um, irá utilizar apenas o primeiro). Permite o cadastro de ids de produtos que irão aparecer como ‘Produtos sugeridos’ na tela de busca. Só irá exibir estes produtos enquanto o usuario não iniciar a digitação de busca. Depois, passara a trazer os resultados da busca do usuario.

## Inputs

<b>active</b>: Se estiver ativo exibe inicialmente estes produtos como produtos sugeridos, até o usuario iniciar a digitação de busca. Se estiver false, buscará pelo ultimo termo das buscas recentes, caso o usuário não tenha buscas recentes os produtos sugeridos serão baseados no primeiro termo dos ‘em alta’.

<b>product\_ids</b>: lista de ids que deverão ser exibidos como produtos sugeridos. os ids dos produtos devem ser separados por ;
