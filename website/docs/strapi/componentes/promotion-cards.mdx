# Promotion Cards

Importante: O cadastro das promoções em si, ou seja, valores reais, duração e tudo mais, não é feito pelo Strapi. Esse componente só é responsável pela visualização na Sacola dessas informações. É importante que em ambos cadastros, Strapi e VTEX estejam alinhados para evitar possíveis problemas. Componente de exibição de promoção ativa, mostrando ao usuário quanto falta para ativar determinada promoção. Possuindo um CTA de navegação dinâmica e vários textos informativos.
