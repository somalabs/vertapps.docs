# Promotion Cards

Importante: O cadastro das promoções em si, ou seja, valores reais, duração e tudo mais, não é feito pelo Strapi. Esse componente só é responsável pela visualização na Sacola dessas informações. É importante que em ambos cadastros, Strapi e VTEX estejam alinhados para evitar possíveis problemas. Componente de exibição de promoção ativa, mostrando ao usuário quanto falta para ativar determinada promoção. Possuindo um CTA de navegação dinâmica e vários textos informativos.

## Inputs

<b>Está ativa?:</b> Determina se o componente será mostrado ou não para os usuários.<br />

<b>Icon</b>: Uma imagem que poderá ser exibida como um ícone, logo ao lado do texto.<br /><br /><b>Id da promoção:</b> O id da promoção criada na VTEX.<br /><br /><b>Título:</b> Um título que aparecerá em destaque no card de promoção.<br /><br /><b>Subtítulo:</b> Um subtítulo, ou descrição, que será exibido logo abaixo do título.<br /><br /><b>Texto de feedback:</b> Um texto informativo que será exibido quando a promoção fora ativada para o usuário, ou seja, quando ele cumprir com os requisitos da promoção. Poderá ser usadas tags HTML para estilizar o texto, além de placeholders como &#123;valor-restante-para-habilitar&#125;, que é justamente o valor que falta para a promoção ser ativada para o usuário.

[Ver documentação de preenchimento em HTML](https://app.notion.com/p/8050d90e377246f5b1765cc0828a6718#262690e9a7e280c2bb84fdb654cc3949)<br /><br /><b>Subtitulo do feedback:</b> Texto abaixo do título de feedback mostrado quando a promoção estiver aplicada. Poderá ser usadas tags HTML para estilizar o texto.<br /><br /><b>Mostrar barra de progresso?:</b> Define se deve ser exibido uma barra de progresso que mostra o quanto falta para o usuário atingir os requisitos da promoção.<br /><br /><b>Texto do botão:</b> Define o texto do CTA do Card de Promoção.<br /><br /><b>Navegação do botão:</b> A navegação dinâmica a ser executada quando o usuário clicar no botão de CTA.<br /><br /><b>Tema:</b> O tema do card de promoção, podendo ser claro ou escuro.<br /><br /><b>Tipo de entrega:</b> Caso seja necessário, a promoção poderá ser filtrada por tipo de entrega, isso é, se o valor selecionado for “Entrega Normal”, e a Entrega Normal não estiver disponível para o usuário, a promoção não será exibida.<br />
