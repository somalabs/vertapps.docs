# Meus Interesses

Componente de card composto por ícone, título, subtítulo e CTA.

<Chips>
  <Chip tone="coral">Meus Interesses</Chip>
  <Chip tone="teal">CMS</Chip>
</Chips>

## Inputs

![Meus Interesses — figura 1](/img/strapi/meus-interesses/img-01.webp)

<b>title:</b> deve ser inserido o título para o card. Campo obrigatório.

<b>subtitle:</b> deve ser inserido o texto que será exibido abaixo do título no card. Campo obrigatório.

<b>call\_to\_action\_with\_interests (para usuários COM interesses cadastrados):</b> deve ser inserido o texto do CTA para usuários com interesses já cadastrados. Campo obrigatório.

<b>call\_to\_action\_without\_interests (para usuários SEM interesses cadastrados):</b> deve ser inserido o texto do CTA para usuários sem interesses já cadastrados. Campo obrigatório.

<b>icon:</b> deve ser inserida uma imagem. Campo obrigatório.
