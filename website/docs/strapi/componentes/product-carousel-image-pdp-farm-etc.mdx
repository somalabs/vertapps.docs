## Inputs

![Product Carousel Image (PDP Farm ETC) — figura 1](/img/strapi/product-carousel-image-pdp-farm-etc/img-01.webp)

<b>Título:</b> Título do componente. Campo obrigatório.

<b>Subtítulo:</b> Subtítulo do componente. Campo obrigatório.

<b>Call to Action:</b> Texto do botão que leva para a PDC completa. Campo opcional.

<b>Filtro de categoria:</b> deve ser inserido o caminho para o Intelligent Search da Vtex retornar os produtos de determinada categoria ou coleção. Campo obrigatório.

<b>orderby:</b> Ordenação dos produtos no carrossel. Campo opcional.

<b>text\_color:</b> Cor do texto. Campo opcional.

<b>background\_color:</b> Cor de fundo. Campo opcional.

<b>Imagem:</b> Imagem que vai ficar abaixo do carrosel de produtos, no fim do componente. Campo obrigatório.
