## Inputs

<b>items:</b> itens que serão exibidos no carrossel. (repetível)

<b>media:</b> Imagem. Campo obrigatório.

<b>navigate\_to:</b> URL de navegação que será executada ao clicar no banner. Campo opcional. Segue o padrão de [navegação dinâmica](../navegacao-dinamica.mdx). Campo obrigatório.
