## Inputs

![Sign Up Login (NV) — figura 1](/img/strapi/componentes-nv/sign-up-login-nv/img-01.webp)

<b>title:</b> deve ser inserido o texto que será exibido no título do componente. Campo obrigatório.

<b>description:</b> deve ser inserido o texto que será exibido no subtítulo do componente. Campo obrigatório.

<b>buttons\_direction:</b> os botões podem estar alinhados em linha ou em coluna. O default é em column. Opções (escrever dessa forma): column e row. Campo obrigatório.

<b>image:</b> imagem que vai ser mostrada no componente. Campo opcional.
