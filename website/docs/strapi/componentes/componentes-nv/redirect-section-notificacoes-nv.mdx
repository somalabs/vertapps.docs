# Redirect Section(Notificações NV)

Componente Redirect Section e mostrado na tela de  notificações na nv, quando o usuário realizou o login e ainda não tem notificações.

  <Chip tone="coral">Redirect Section(Notificações NV)</Chip>

</Chips>

![Redirect Section(Notificações NV) — figura 1](/img/strapi/componentes-nv/redirect-section-notificacoes-nv/img-01.webp)

## Inputs

<b>title:</b> Deve ser inserido o texto que aparecerá em destaque  (obrigatório).

<b>subtitle:</b> Deve ser inserido o texto que ficará abaixo do título, como descrição do componente (obrigatório).

<b>call\_to\_action:</b> Deve ser inserido o texto que aparecerá como titulo do botão (obrigatório).

<b>category\_filter:</b> A filtragem de pesquisa que será feita quando o usuário clicar no botão. (Obrigatório)
