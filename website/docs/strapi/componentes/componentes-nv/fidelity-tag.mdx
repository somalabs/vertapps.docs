## Inputs

![Fidelity Tag — figura 2](/img/strapi/componentes-nv/fidelity-tag/img-02.webp)

<b>orderBy:</b> Ordenação dos produtos na PDC quando usuário clicar na tag a partir da PDP. Campo opcional.

<b>background\_color:</b> Cor do fundo da Tag. Campo obrigatório.

<b>text\_color:</b> Cor do texto da Tag. Campo obrigatório.

<b>border\_color:</b> Cor da borda da Tag. Campo opcional.

<b>filter\_category\_or\_cluster:</b> deve ser inserido o caminho para o Intelligent Search da Vtex. Utilizado para identificar a coleção ou categoria <b>do produto</b> na qual vai aparecer a TAG.  Campo obrigatório.<br />Caso seja productClusterID, preencha apenas com o ID da coleção.<br />Caso seja productClusterName, preencha apenas com o nome da coleção.
