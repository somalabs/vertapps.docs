# Redirecionamento busca

Para que o redirecionamento customizável funcione é necessário que seja cadastrado dentro de Collections -> Deeplinks no Strapi, a URL que seja válida para direcionamento.<br />Por exemplo:

<Chips>
  <Chip tone="coral">Redirecionamento busca</Chip>
  <Chip tone="teal">CMS</Chip>
</Chips>

A URL [https://www.farmrio.com.br/farm-etc/novidades](https://www.farmrio.com.br/farm-etc/novidades). A partir do cadastro na VTEX ela será redirecionada quando for buscada pelas palavras chaves conforme imagem abaixo:
