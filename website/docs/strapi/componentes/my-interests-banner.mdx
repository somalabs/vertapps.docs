# My Interests Banner

Componente de banner de imagem que diferencia-se à depender de o usuário ter interesses cadastrados ou não.

<Chips>
  <Chip tone="coral">My Interests Banner</Chip>
  <Chip tone="teal">CMS</Chip>
</Chips>

## Inputs

![My Interests Banner — figura 1](/img/strapi/my-interests-banner/img-01.webp)

<b>título (para usuários com interesses cadastrados):</b> deve ser inserido o título para o banner de usuários com interesses já cadastrados, que ficará sobreposto à imagem. Campo opcional.

<b>subtítulo (para usuários com interesses cadastrados):</b> deve ser inserido o texto que será exibido abaixo do título no banner para usuários com interesses cadastrados. Campo opcional.

<b>título do CTA (para usuários com interesses cadastrados) :</b> deve ser inserido o título do CTA para usuários com interesses já cadastrados. Campo opcional.

<b>imagem (para usuários com interesses cadastrados):</b> deve ser inserida uma imagem simples e sem textos para ser exibida ao fundo do banner de usuários com interesses já cadastrados. Campo obrigatório.

<b>imagem (para usuários sem interesses cadastrados):</b> deve ser inserida uma imagem com textos e informações para ser exibida como banner para usuários sem interesses cadastrados. Campo obrigatório.
