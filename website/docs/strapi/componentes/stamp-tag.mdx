# Stamp Tag

Componente de Tag textual, utilizado no Card de produto do ETC, é exibido por cima da imagem do produto.

<Chips>
  <Chip tone="coral">Stamp Tag</Chip>
  <Chip tone="teal">CMS</Chip>
</Chips>

## Inputs

<b>tag\_text:</b> Texto da tag a ser exibida

<b>filter\_category\_or\_cluster</b>: Categoria das quais os produtos correspondentes devem exibir a tag.

<b>colors:</b> Definição das cores da tag
