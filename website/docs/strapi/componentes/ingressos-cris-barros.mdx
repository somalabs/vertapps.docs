## Inputs

![Inputs — Ingressos (Cris Barros)](/img/strapi/ingressos-cris-barros/inputs.webp)

| Campo | Descrição |
|---|---|
| **Imagem de Capa (Banner)** | Imagem de capa do ingresso exibida no topo do card (opcional). |
| **Imagem de Perfil (Logo)** | Imagem de perfil/logo exibida sobre o banner (opcional). |
| **Imagem de Perfil (Logo)** | não funciona sem Imagem de Capa (Banner) |
| **Título Principal** | Título principal do ingresso exibido em destaque (Obrigatório). Ex: DESFILE |
| **Subtítulo** | Subtítulo ou tema do evento exibido abaixo do título (opcional). Ex: COLEÇÃO OUTONO/INVERNO 26 |
| **Título do Cabeçalho** | Texto exibido acima do título principal como destaque (opcional). Ex: CONVITE EXCLUSIVO |
| **Local** | Nome do local onde ocorrerá o evento (Obrigatório). Ex: PINACOTECA DE SAO PAULO, SP |
| **Endereço** | Endereço completo do evento (Obrigatório). Ex: PRAÇA DA LUZ, 2, BOM RETIRO |
| **Instruções (Descrição)** | Texto informativo com instruções ou regras do evento (opcional). Ex: O convite é pessoal e intransferível. |
| **Identificador / Código** | Código único do ingresso usado para integração com Master Data (Obrigatório). ⚠️ Deve ser exatamente igual ao campo "ID do Evento" no Master Data. Ex: VIP-CRIS-2026-001 |
