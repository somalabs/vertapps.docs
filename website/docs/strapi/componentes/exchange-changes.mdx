Campo que, quando preenchido, substitui o valor padrão de Troca e Devolução na PDP.

## Inputs

| Campo | Descrição |
|---|---|
| **Content** | conteúdo do troca e devolução |
| **LinkText** | Texto que aparece como botão com link, que ao ser clicado, redireciona para a url no campo linkUrl. |
| **LinkUrl** | Link para onde o usuário deve ser redirecionado |
