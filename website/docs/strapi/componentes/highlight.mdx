# Highlight

Componente informativo destinado a pequenos avisos (highlights)

<Chips>
  <Chip tone="coral">Highlight</Chip>
  <Chip tone="teal">CMS</Chip>
</Chips>

## Inputs

![Highlight — figura 1](/img/strapi/highlight/img-01.webp)

<b>image:</b> deve ser inseria a imagem que será exibida no item. Campo obrigatório.

<b>title:</b> deve ser inserido o texto que será exibido no título do item. Campo obrigatório.

<b>subtitle:</b> deve ser inserido o texto que será exibido como subtítulo do item. Campo obrigatório.

:::tip

Pode adicionar quantos itens quiser para compor o carrossel de highlights. Para adicionar um novo item, clicar no botão <i>“+ Add an entry”</i>

:::
