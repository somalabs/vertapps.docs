## Inputs

![Carousel List — figura 2](/img/strapi/carousel-list/img-02.webp)

<b>items:</b> itens que serão exibidos no carrossel. (repetível)

<b>media:</b> Imagem ou vídeo do item. Campo obrigatório.

:::warning

Para vídeo, sugere-se que possuam até 3MB para que seja minimizado o risco de problemas com a experiência do usuário em seu dispositivo, que vão desde fluidez corrompida dos vídeos à fechamento inesperado da aplicação.

:::

<b>coupon:</b> Cupom que será aplicado ao clicar no banner. Campo opcional.

<b>navigate\_to:</b> URL de navegação que será executada ao clicar no banner. Campo opcional. Segue o padrão de [navegação dinâmica](../navegacao-dinamica.mdx).

<b>banner\_name\_ga4:</b> ID e nome da promoção usados para eventos de analytics, separados por ///. Campo obrigatório.

<b>lista de botões</b>: Botões com navegação dinâmica para serem exibidos no carousel list, é permitido no máximo 3 botões. Campo opcional.

<b>clusters:</b> Campo para ser preenchido caso esse item de banner deva ser segmentado por clusters de clientes. Nota: Somente marcas onde é possivel a segmentação de componentes por clusters, isso deverá ser preenchido. Segue documentação caso haja dúvidas no seu preenchimento: [Documentação de clusters dinâmicos](https://app.notion.com/p/8050d90e377246f5b1765cc0828a6718#c97433c3891e437ba3385cf11d1d402d).

<b>secondary\_media:</b> Item que deve ser preenchido caso deva ser exibido mais um banner, logo abaixo do primeiro, tendo um próprio CTA ou cupom. Campo opcional.

<b>autoplay:</b> Indica se o carrossel deverá passar entre os banners automaticamente, sem que o usuário precise interagir com o componente. Campo opcional.

<b>loop:</b> Indica se o carrossel deve voltar ao início após exibir o último banner. Campo opcional.

<b>delay:</b> Quantidade de segundos que serão esperados antes de transicionar para o próximo banner caso o autoplay esteja ativado. Campo opcional.
