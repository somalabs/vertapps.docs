# List Links

Componente lista de links uteis ao menu

<Chips>
  <Chip tone="coral">List Links</Chip>
  <Chip tone="teal">CMS</Chip>
</Chips>

## Inputs

![List Links — figura 1](/img/strapi/list-links/img-01.webp)

<b>title:</b> deve ser inserido o texto que será exibido no título da lista. O campo é obrigatório.

items: Aqui fica todos os items da lista dos links

<b>title:</b> deve ser inserido o texto que será exibido como título do item. O campo obrigatório.

ulr: deve ser inserido o a url da página web para o redirecionamento do usuário, o campo não é obrigatório

navigate\_to: campo deve ser inserido no caso do usuário para redirecionar usuário para plp

:::tip

Pode adicionar quantos itens quiser para compor a lista de links. Para adicionar um novo item, clicar no botão <i>“+ Add an entry”</i>

:::
