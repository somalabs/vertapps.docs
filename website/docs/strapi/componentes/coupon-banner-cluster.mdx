# Coupon Banner - Cluster

Este componente é igual ao Coupon Banner comum, com um campo a mais para ser preenchido, que é o campo de “clusters”.A diferença é que esse componente só será exibido para clientes que possuam os clusters passados no campo “clusters”.

<Chips>
  <Chip tone="coral">Coupon Banner - Cluster</Chip>
  <Chip tone="teal">CMS</Chip>
</Chips>

## Inputs

<b>coupon\_banner:</b> deve ser preenchido conforme [Documentação](https://app.notion.com/p/8050d90e377246f5b1765cc0828a6718#2aed0a0f6b3b49c7809d204e668f91d3)

<b>clusters</b>: A filtragem por clusters que o cupom terá. Para possíveis dúvidas de como preencher, seguir essa documentação: [Documentação de clusters dinâmicos](https://app.notion.com/p/8050d90e377246f5b1765cc0828a6718#c97433c3891e437ba3385cf11d1d402d).
