# Meus interesses com header

Componente de banner de imagem que diferencia-se à depender de o usuário ter interesses cadastrados ou não.

<Chips>
  <Chip tone="coral">Meus interesses com header</Chip>
  <Chip tone="teal">CMS</Chip>
</Chips>

![Meus interesses com header](/img/strapi/meus-interesses-com-header/preview.webp)

## Inputs

![Inputs — Meus interesses com header](/img/strapi/meus-interesses-com-header/inputs.webp)

| Campo | Descrição |
|---|---|
| **título (para usuários com interesses cadastrados),** | deve ser inserido o título para o banner de usuários com interesses já cadastrados, que ficará sobreposto à imagem. Campo obrigatório. |
| **título do CTA (para usuários com interesses cadastrados),** | deve ser inserido o título do CTA para usuários com interesses já cadastrados. Campo opcional. |
