# Meus interesses com header

Componente de banner de imagem que diferencia-se à depender de o usuário ter interesses cadastrados ou não.

## Inputs

<b>title:</b> título (para usuários com interesses cadastrados), deve ser inserido o título para o banner de usuários com interesses já cadastrados, que ficará sobreposto à imagem. Campo obrigatório.

<b>subtitle:</b> subtítulo (para usuários com interesses cadastrados), deve ser inserido o texto que será exibido abaixo do título no banner para usuários com interesses cadastrados. Campo opcional.

<b>call\_to\_action:</b> título do CTA (para usuários com interesses cadastrados), deve ser inserido o título do CTA para usuários com interesses já cadastrados. Campo opcional.

<b>image\_interests (para usuários com interesses cadastrados):</b> deve ser inserida uma imagem simples e sem textos para ser exibida ao fundo do banner de usuários com interesses já cadastrados. Campo obrigatório.

<b>image\_no\_interests (para usuários sem interesses cadastrados):</b> deve ser inserida uma imagem com textos e informações para ser exibida como banner para usuários sem interesses cadastrados. Campo obrigatório. (A própria imagem deve conter os textos a serem exibidos).

<b>header\_color:</b> Para definir a cor do header, selecione entre tema ‘claro’ e ‘escuro’, conforme a media de fundo selecionada.
