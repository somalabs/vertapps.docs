# Created Suitcase

Componente que renderiza a mensagem de mala vazia para o usuário e cria sugestões com category banner e showcase dentro da mala do usuário. Disponível na aba Favoritos \> Mala de viagem

<Chips>
  <Chip tone="coral">Created Suitcase</Chip>
  <Chip tone="teal">CMS</Chip>
</Chips>

### created-suitcase-empty

![Created Suitcase — figura 2](/img/strapi/created-suitcase/img-02.webp)

<b>title:</b> Título do componente. Campo obrigatório.

<b>button\_title:</b> Título do botão de redirecionamento. Campo obrigatório.

<b>subtitle:</b> Subtítulo do do componente. Campo obrigatório.

<b>filter\_category\_or\_cluster:</b> Para onde será feito o redirecionamento depois de clicado no botão. Campo obrigatório.

<b><br />obs: </b>category-banner e showcase-list, ver a documentação
