## Inputs

![Spot Product — figura 2](/img/strapi/spot-product/img-02.webp)

<b>title:</b> Título do componente. Campo obrigatório.

<b>subtitle:</b> Subtítulo do componente. Campo obrigatório.

<b>call\_to\_action:</b> Texto do botão que leva para a PDC completa. Campo opcional.

<b>filter\_category\_or\_cluster:</b> deve ser inserido o caminho para o Intelligent Search da Vtex retornar os produtos de determinada categoria ou coleção (caminho varia de marca para marca). Campo obrigatório.

<b>orderby:</b> Ordenação dos produtos no carrossel. Campo opcional.

<b>search\_title:</b> Ordenação dos produtos no carrossel. Campo opcional.

<b>filter\_size:</b> Ordenação dos produtos no carrossel. Campo opcional.

<b>filter\_color:</b> Deve ser inserida a especificação do filtro de cor. Campo opcional.

<b>query:</b> Deve ser inserida a especificação de filtro por palavra chave. Campo opcional.
