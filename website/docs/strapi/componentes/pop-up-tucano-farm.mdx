<DocTitle brand="Farm">Pop Up Tucano</DocTitle>

Consiste em um componente único (imagem), exibido como um pop up na home, que pode possuir uma navegação dinâmica ao clicar no botão ou fecha ao clicar no X.

<Chips>
  <Chip tone="coral">Pop Up Tucano</Chip>
  <Chip tone="amber">Farm</Chip>
  <Chip tone="teal">CMS</Chip>
</Chips>

## Inputs

<b>O Pop Up está ativo?:</b> True - ativa o componente. False - desativa o componente. Campo obrigatório.

<b>Navegação dinâmica:</b> Navegação dinâmica realizada ao clicar no botão. Campo obrigatório.<br />Ex: pdp/175042

<b>Texto do botão:</b> Campo para cadastrar o texto do botão. Campo opcional, o padrão é “Vem conferir”(o que está no figma).

<b>Texto da imagem:</b> Campo para cadastrar o texto da imagem. Campo opcional, o padrão é “Tem cheirinho de novidade…”(o que está no figma).
