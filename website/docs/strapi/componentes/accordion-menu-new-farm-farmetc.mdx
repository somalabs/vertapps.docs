## Inputs

![Inputs — Accordion Menu New (Farm & FarmETC)](/img/strapi/accordion-menu-new-farm-farmetc/inputs.webp)

| Campo | Descrição |
|---|---|
| **Está ativa** | ?: Caso false, o componente não é exibido. |
| **Cor do título** | Cor do título do menu. |
| **Navegação dinâmica** | Caso o item de menu não tenha items, ou seja, deve redirecionar ao ser clicado, e não abrir o próximo nível de menu, é neste campo que deve ser preenchido o redirecionamento esperado (conforme documentação da navegação dinâmica). |
| **Header image** | Imagem que aparece no header do menu, quando está exibindo a listagem do campo ‘items’. (Não funciona pro MENU ETC) |
| **Quantidade de selos** | Valor que aparecerá em formato de notificação ao lado do título do item. |
| **Caso true, exibe um “Ver tudo \>” que navega para a mesma que a** | Navegação dinâmica. OBS: FUNCIONA APENAS NO MENU NOVO, APÓS O REDESIGN. NÃO ALTERA EM NADA NO MENU ANTIGO. |
