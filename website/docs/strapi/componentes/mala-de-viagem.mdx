Componente que renderiza o componente de sugestão de Mala de viagem. Disponível na aba Favoritos \> Mala de viagem

## Inputs

![Mala de viagem — figura 3](/img/strapi/mala-de-viagem/img-03.webp)

<b>component\_title:</b> Título do componente. Campo obrigatório.

<b>component\_subtitle:</b> Subtítulo do componente. Campo obrigatório.

<b>id\_list:</b> Id de todos os produtos separados por virgula. Campo obrigatório.

<b>image:</b> Imagem de capa da mala. Campo obrigatório.
