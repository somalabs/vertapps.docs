## Inputs

<b>title:</b> Título principal (ex: nossas categorias).

<b>subtitle:</b> Texto complementar ao título. Opcional<b>.</b>

<b>call\_to\_action:</b> Texto do botão principal de ação<b><br />navigate\_to: </b>Define o redirecionamento ao clicar no botão cta. Deve ser preenchido conforme a documentação da navegação dinamica.

<b>backgroud:</b>  Cor de fundo do componente. Opcional<b>.</b>

### Items

Lista de categorias exibidas na grade. Este campo é <b>obrigatório</b> para que o componente funcione corretamente.

<b>media:</b> Upload da imagem exibida no componente. Campo obrigatório.

<b>navigate\_to:</b> Define o redirecionamento ao clicar na imagem. Deve ser preenchido conforme a documentação da navegação dinamica. Campo obrigatório.
