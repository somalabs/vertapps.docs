# Badge Discount

Componente utilizado para exibir um selo de desconto, com imagem e código de cupom.

<Chips>
  <Chip tone="coral">Badge Discount</Chip>
  <Chip tone="teal">CMS</Chip>
</Chips>

## Inputs

<b>media:</b> Upload da imagem exibida no componente. Aceita formatos `.gif`, `.jpg`, ou `.png`. Campo obrigatório.

<b>coupon:</b> Código do cupom que será copiado ao clicar na imagem. Deve conter o valor real do cupom (ex: `etc20`). Opcional<b>.</b>

<b>backgroud:</b> Cor de fundo do componente. Opcional<b>.</b>
