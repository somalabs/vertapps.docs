## Input

Cada componente de deeplink cadastrado corresponde a um deeplink do app.

![Deeplink — figura 1](/img/strapi/deeplink/img-01.webp)

<b>URL</b>: Neste campo deve ser preenchido com o deeplink completo, como será compartilhado. É este link que será comparado com o que o usuário clicou. Se eles forem iguais, executará o redirecionamento definido na navegação dinamica.

“https://www.marca.com.br/novidades”

Esse campo é altamente personalizavel depois do domínio “www.marca.com.br/”. é possivel criar a url que quiser como “www.marca.com.br/pra-voce-maria” ou ““www.marca.com.br/o-melhor-vestido”.

<b>Navegação dinâmica:</b> Este campo é o que define como o usuário será redirecionado ao abrir determinado deeplink. Deve ser preenchido conforme [documentação própria](../navegacao-dinamica.mdx).

<b>Título:</b> Título que aparecerá na tela de listagem de produtos, quando redirecionado.

<b>Ordenação</b>: Ordenação dos produtos na navegação. (Caso não definido, segue a ordenação manual da vtex).

## Exemplos

### Deeplink para menu

Conforme navegação dinamica, é possível redirecionar o usuário para uma tab especifica do menu, basta apenas adicionar ‘/nome da tab’, após “/menu”.<br />Caso o nome da tab fosse “mega promo”, o campo de navegação dinâmica deveria ser preenchido como “/menu/mega promo”.
