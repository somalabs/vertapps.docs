## Inputs

![Inputs — Deeplink](/img/strapi/deeplink/inputs.webp)

| Campo | Descrição |
|---|---|
| **URL** | Neste campo deve ser preenchido com o deeplink completo, como será compartilhado. É este link que será comparado com o que o usuário clicou. Se eles forem iguais, executará o redirecionamento definido na navegação dinamica. “https://www.marca.com.br/novidades” Esse campo é altamente personalizavel depois do domínio “www.marca.com.br/”. é possivel criar a url que quiser como “www.marca.com.br/pra-v |
| **Ordenação** | Ordenação dos produtos na navegação. (Caso não definido, segue a ordenação manual da vtex). |
