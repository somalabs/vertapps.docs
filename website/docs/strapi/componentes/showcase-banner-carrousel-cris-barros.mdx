<DocTitle brand="Cris Barros">ShowCase Banner Carrousel</DocTitle>

Componente de destaque de imagens em carrossel. O componente pode receber uma imagem que já contenha textos incorporados ou permitir a adição de uma imagem separada com um título e um texto para o botão.

  <Chip tone="teal">CMS</Chip>
</Chips>

## Inputs

<b>title:</b> deve ser inserido o texto que será exibido no título do componente. Campo opcional

<b>call\_to\_action:</b> deve ser inserido o texto que será exibido no botão do componente. Campo opcional

<b>navigate\_to:</b> Url de destino ao clicar na seta, para onde o usuário é redirecionado a partir do respectivo banner. (Campo obrigatório).  Deve seguir [o padrão de redirecionamento da navegação dinâmica](../navegacao-dinamica.mdx). <br />Exemplo: “<b>external-link/</b>[https://www.bynv.com.br/quemsomos](https://www.bynv.com.br/quemsomos)”

<b>Banner:</b> imagem que vai ser mostrada no componente. Campo obrigatório.
