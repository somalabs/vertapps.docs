<DocTitle brand="Cris Barros">Personal Shopper</DocTitle>

Consiste em um componente aonde é possível cadastrar uma lista de contatos para serem exibidos na Aba Conta/Perfil.

<Chips>
  <Chip tone="coral">Personal Shopper</Chip>
  <Chip tone="amber">Cris Barros</Chip>
  <Chip tone="teal">CMS</Chip>
</Chips>

## Inputs

<b>Texto:</b> É o texto que vai ser exibido no item. Campo obrigatório.

<b>Telefone:</b> Campo para cadastrar o número do Whatsapp que irá redirecionar. Campo obrigatório.
