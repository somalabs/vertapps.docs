# Tag Image Background

Componente de tag, que tem o fundo de imagem, e texto. É exibida na PDC, junto das outras tags, e na PDP acima do título do prduto.

## Inputs

![Inputs — Tag Image Background](/img/strapi/tag-image-background/inputs.webp)

| Campo | Descrição |
|---|---|
| **Text** | Texto da tag |
| **text_color** | Cor do texto (definir considerando a cor da imagem de fundo aplicada). |
| **filter_category_or_cluster** | coleção de produtos que devem exibir a tag |
| **image_background** | imagem de fundo da tag. (Reparar no formato aplicado). |
