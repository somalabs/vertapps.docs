# Tag Image Background

Componente de tag, que tem o fundo de imagem, e texto. É exibida na PDC, junto das outras tags, e na PDP acima do título do prduto.

<Chips>
  <Chip tone="coral">Tag Image Background</Chip>
  <Chip tone="teal">CMS</Chip>
</Chips>

## Inputs

![Tag Image Background — figura 1](/img/strapi/tag-image-background/img-01.webp)

<b>Text</b>: Texto da tag

<b>text\_color</b>: Cor do texto (definir considerando a cor da imagem de fundo aplicada).

<b>filter\_category\_or\_cluster</b>: coleção de produtos que devem exibir a tag

<b>image\_background</b>: imagem de fundo da tag. (Reparar no formato aplicado).
