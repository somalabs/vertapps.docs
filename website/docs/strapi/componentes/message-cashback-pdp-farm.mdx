## Inputs

<b>Message</b>: Texto que será exibido na tela (Obrigatório).

<b>Assignment</b>: Coleções onde a mensagem não será exibida. Pode ser uma lista, separada por ";” sem espaços entre os itens. Caso não seja cadastrado, a mensagem ficará visível em todas as coleções, exceto aquelas que não são elegíveis para cashback.

<b>Is\_active</b>: Identifica se a mensagem está ativa ou não (Obrigatório).

<b>Message\_text\_color</b>: Cor do texto da mensagem (Obrigatório).
