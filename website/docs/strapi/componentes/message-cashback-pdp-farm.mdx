## Inputs

![Inputs — Message cashback pdp (Farm)](/img/strapi/message-cashback-pdp-farm/inputs.webp)

| Campo | Descrição |
|---|---|
| **Message** | Texto que será exibido na tela (Obrigatório). |
| **Assignment** | Coleções onde a mensagem não será exibida. Pode ser uma lista, separada por ";” sem espaços entre os itens. Caso não seja cadastrado, a mensagem ficará visível em todas as coleções, exceto aquelas que não são elegíveis para cashback. |
| **Is_active** | Identifica se a mensagem está ativa ou não (Obrigatório). |
| **Message_text_color** | Cor do texto da mensagem (Obrigatório). |
