## Inputs

| Campo | Obrigatório | Descrição |
|---|---|---|
| **texto da tipbar** | Sim | Texto exibido na tipbar. |
| **cor do texto** | Sim | Cor do texto da tipbar. |
| **cor de fundo** | Sim | Cor de fundo da tipbar. |
| **texto do cta** | Não | Texto do CTA à direita. Se vazio, a tipbar fica como texto sublinhado com ícone para fechar. |
| **navegar para** | Sim | Caminho de redirecionamento (ver formatos abaixo). |

## Formatos de `navegar para`

| Tipo | Formato do campo |
|---|---|
| Webview | `webview/https://www.farmrio.com.br/sustentabilidade/natureza` |
| Link externo | `external-link/https://www.farmrio.com.br/sustentabilidade/natureza` |
| LP | `lp/lp-verao-24` |
| PDP | `pdp/73873` |
| PDC / PLP | `plp` |

### Quando o destino é PDC

Se `navegar para` for uma PDC, estes campos extras entram:

| Campo | Obrigatório | Descrição |
|---|---|---|
| **filtro de categorias** | Não | Caminho no Intelligent Search da VTEX para categoria/coleção. |
| **filtro de cor** | Não | Spec de filtro de cor na listagem. |
| **filtro de tamanho** | Não | Spec de filtro de tamanho na listagem. |
| **palavra-chave de busca** | Não | Filtro por palavra-chave na listagem. |
| **ordenação da listagem** | Sim | Critério de ordenação dos produtos na PLP. |
