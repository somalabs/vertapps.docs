## Inputs

![Pickup Tag — figura 2](/img/strapi/pickup-tag/img-02.webp)

<b>title:</b> deve ser inserido o texto que será exibido dentro da tag. Campo obrigatório.

<b>background\_color:</b> deve ser inserida a cor de fundo da tag. Campo obrigatório.

<b>border\_color:</b> deve ser inserida a cor da borda da tag. Campo obrigatório.

<b>title\_color:</b> deve ser inserida a cor do texto exibido dentro da tag. Campo obrigatório.

<b>active:</b> deve ser escolhida a opção de ativar ou desativar a tag. A tag só será exibida caso a opção “Ativar tag” esteja selecionada. Campo obrigatório.
