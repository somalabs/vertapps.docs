# Tema visual

O site usa **exatamente** os tokens de `prompt-construcao-apresentacao.md`: tema escuro quente, sóbrio e executivo. Coral é destaque/ação. Não criar paleta paralela.

## Anatomia de uma página

1. **Kicker** — caixa alta, letter-spacing largo (ex.: `04 · Modelo-alvo`).
2. **Título** — grande, com `clamp()`, sem parágrafo longo em seguida.
3. **Lead** — uma ou duas frases em tom `--ink2`.
4. **Chips** — resumo em pílulas com borda da cor do tema.
5. **Cards** — bloco temático: responsável (teal), não é dono (coral), interface (blue).
