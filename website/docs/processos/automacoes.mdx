## 1 · brand-release (abrir homologação)

### 1 · Criar branch de release

A partir de `main` → `release/X.Y.Z`.

### 2 · Codemagic: build + E2E

Gera o build e roda os testes end-to-end na release.

### 3 · Notificar no Teams

Envia o build junto com o resultado dos testes.

### 4 · Atualizar Jira

Move os cards conforme o status da versão gerada.

**Quem:** automação

## 2 · post-brand-release (após lojas)

### 1 · App liberado nas lojas

Gatilho: publicação concluída (App Store / Play Store).

### 2 · Criar a tag

Tag `vX.Y.Z` no commit que foi às lojas.

### 3 · Changelog da marca

Gera o changelog (GitHub Release / artefato da marca).

### 4 · Excluir a release

Remove a branch `release/X.Y.Z` — era temporária.

### 5 · Mover cards no Jira

Cards da versão vão para o status final (ex.: Concluído / em produção).

**Quem:** automação
