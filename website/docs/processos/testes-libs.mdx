# Testes mínimos por lib

Sem teste, a task da lib não está pronta.

| Lib | Mínimo |
|---|---|
| `azzas_ui` | Componentes novos ou alterados → widget tests. |
| `azzas_core` | Repositories e usecases novos → testes unitários. |
| `azzas_commons` | Cubits e métodos novos → testes unitários. |
