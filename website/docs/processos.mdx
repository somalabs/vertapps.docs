## Duas automações do ciclo de versão

Documentação operacional está em [Skills de Release](./skills-release/index.md).

| Momento | Skill | O que faz |
|---|---|---|
| Abrir homologação | `brand-release` | Branch `release/*`, build Codemagic, Teams, Jira Em homologação |
| Depois das lojas | `post-brand-release` | Tag `vX.Y.Z`, GitHub Release, cards concluídos, changelog no Teams |

Guia curto: [Guia rápido](./skills-release/07-guia-rapido.md).

## Pontos de atenção (da fonte HTML)

- Codemagic: parar de clonar as libs.
- Toda PR nas libs vira tag — sem exceção.
- Homolog da marca builda de `release/*`.
- Feature flag obrigatória; revert é fallback.
